# website

## Routes

| URL                | Description                                                                  |
| :----------------- | :--------------------------------------------------------------------------- |
| `/`                | View baseline above the fold, section for experiments, section for scenarios |
| `/experiments`     | List experiments, create experiment                                          |
| `/experiments/:id` | View experiment details, edit experiment, run experiment                     |
| `/scenarios`       | List scenarios, create scenario                                              |
| `/scenarios/:id`   | View scenario details, edit scenario, view baseline results                  |
