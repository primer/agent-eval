Add `ui dev` to browse local benchmark, experiment, and scenario results with automatic refresh, and `ui build` to export a static results site. Install the opt-in `@primer/agent-eval-website` package to use the shared Next.js and Primer UI; the core package does not install UI dependencies. Use `--base-path` when exporting for a hosting subpath.
